# EasyTier 内核配置使用指南

### 1. 放置二进制
从 [EasyTier/EasyTier](https://github.com/EasyTier/EasyTier/releases) 下载 Windows 压缩包，解压出 `easytier-core.exe` 放置在 v2rayN 的 `bin/easytier/` 目录下。

### 2. 添加到 v2rayN
1. 打开 v2rayN，点击 `服务器` -> `添加自定义配置服务器`。
2. Core类型选择：`easytier`。
3. 在配置文本框中填入 `p2p-node.txt` 中的参数，按需修改节点 IP、组网名称与组网密码。
